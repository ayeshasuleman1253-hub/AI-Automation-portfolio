# Fix Now – Customer Email Automation

## Project Overview
An automated email confirmation system for a home-services platform.

## Problem
Manually responding to every customer request takes time.

## Solution
Built a Make.com workflow that detects new customer entries in Google Sheets and sends personalized confirmation emails through Gmail.

## Workflow
1. Customer submits their information.
2. Google Sheets stores the request.
3. Make.com detects the new row.
4. Gmail sends a personalized confirmation email.

## Tools Used
- Make.com
- Google Sheets
- Gmail

## Skills Practiced
- Triggers and actions
- Connecting applications
- Data mapping
- Workflow testing

## Result
Successfully tested the automation with sample customer entries.
